# processes-CHP-1-dz

Домашнє завдання з курсу **Системне програмування**.

Тема: **Процеси**.

## Що реалізовано

У файлі `Program.cs` знаходиться один консольний C# застосунок, який виконує всі 4 завдання:

1. Запускає дочірній процес, чекає його завершення та показує код завершення.
2. Запускає дочірній процес і дає вибір: чекати завершення або примусово завершити процес.
3. Передає дочірньому процесу два числа та операцію `+`, `-`, `*`, `/`.
4. Передає дочірньому процесу шлях до файлу або папки та слово для пошуку.

Дочірнім процесом є той самий exe-файл, але запущений зі службовими аргументами командного рядка.

## Як зібрати

Через Visual Studio:

1. Створіть Console App на C#.
2. Замініть вміст `Program.cs` кодом із цього репозиторію.
3. Запустіть проєкт.

Через компілятор `csc`, якщо він доступний у терміналі:

```powershell
csc Program.cs
```

## Як запустити

Після збірки:

```powershell
.\Program.exe
```

У меню виберіть номер потрібного завдання.

## Приклад для завдання 3

Введення:

```text
Перше число: 7
Друге число: 3
Операція (+, -, *, /): +
```

Результат у дочірньому процесі:

```text
Отримані аргументи:
Перше число: 7
Друге число: 3
Операція: +
Результат: 10
```

## Приклад для завдання 4

Введення:

```text
Шлях до файлу або папки: E:\someFolder
Слово для пошуку: bicycle
```

Якщо шлях є папкою, програма рахує входження слова у всіх файлах цієї папки та її підпапок.
